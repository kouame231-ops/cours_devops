# ContactsManager — Gestionnaire de Contacts en Java

## Description
Ce projet implémente un gestionnaire de contacts en Java (POO).
Les contacts sont stockés dans un tableau d'objets Contact géré par la classe ContactsManager.

## Structure du projet
- Contact.java          : Classe représentant un contact
- ContactsManager.java  : Classe gérant le tableau de contacts
- Main.java             : Programme principal
- README.md             : Documentation

## Compilation et exécution
javac Contact.java ContactsManager.java Main.java
java Main
